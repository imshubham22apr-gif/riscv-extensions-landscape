# SwiftType - Premium Typing Speed Test

SwiftType is a minimalist, high-fidelity browser application designed to measure text-input velocity (Words Per Minute) with visual precision.

Live Demo: [https://typing-speed-test-project-psi.vercel.app](https://typing-speed-test-project-psi.vercel.app)

## Features
- **Real-time WPM calculation**: Calculates your exact typing speed instantly upon completion.
- **Dynamic Character Highlighting**: Character highlights update as you type for immediate visual feedback.
- **Swiss / Bauhaus Aesthetic**: Beautiful grid overlay, warm off-white canvas, and photorealistic stopwatches/pens styling.
- **Arial Typography**: Clean and professional typography layout.

## Technologies Used
- React
- Vite
- Custom CSS Variables

## Getting Started
To run the project locally:
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
